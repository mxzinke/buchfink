Installation

App installieren, Agent verbinden

Zwei Teile: die App Buchfink auf Ihrem Rechner und ein KI-Client, der über MCP mit ihr spricht. Die ausführlichen Anleitungen stehen in der Dokumentation.

Unsignierte Vorschau

Die Installationsdateien von Version 0.3 sind nicht signiert. Das Betriebssystem warnt beim ersten Start. Laden Sie Buchfink nur von der Releases-Seite und probieren Sie es zuerst mit einem Testunternehmen aus.

1. Die App installieren

Herunterladen

Laden Sie buchfink-darwin-universal.zip, entpacken Sie die Datei und ziehen Sie buchfink.app in den Ordner „Programme“. Die App läuft auf Apple Silicon und Intel.

Den ersten Start erlauben

Starten Sie Buchfink. macOS meldet, dass es die App nicht prüfen kann. Öffnen Sie Systemeinstellungen → Datenschutz & Sicherheit und wählen Sie bei der Meldung zu Buchfink Dennoch öffnen.

Meldet macOS, die App sei beschädigt, hilft im Terminal:

xattr -dr com.apple.quarantine /Applications/buchfink.app

Herunterladen und starten

Laden Sie buchfink-windows-amd64.exe, legen Sie die Datei in einen Ordner Ihrer Wahl und starten Sie sie. Ein Installationsprogramm gibt es nicht.

SmartScreen bestätigen

Windows meldet „Der Computer wurde durch Windows geschützt“. Wählen Sie Weitere Informationen und dann Trotzdem ausführen.

Buchfink braucht die WebView2-Laufzeit von Microsoft. Windows 11 bringt sie mit, unter Windows 10 kommt sie meist über Windows Update. Fehlt sie, installieren Sie die Evergreen-Laufzeit von der WebView2-Seite von Microsoft.

Herunterladen und starten

Laden Sie buchfink-linux-amd64.tar.gz, entpacken Sie die Datei und starten Sie Buchfink:

tar -xzf buchfink-linux-amd64.tar.gz && ./buchfink

Die Datei buchfink können Sie in einen Ordner im PATH legen, etwa ~/.local/bin.

Bibliotheken prüfen

Buchfink ist unter Ubuntu 24.04 für x86-64 gebaut und braucht GTK 3, WebKitGTK 4.1 und glibc ab Version 2.34. Unter Debian und Ubuntu installiert sudo apt install libwebkit2gtk-4.1-0 WebKitGTK samt GTK 3, unter Fedora sudo dnf install webkit2gtk4.1.

Wer selbst bauen möchte, folgt der Entwicklungsanleitung.

Erster Start

2. Einrichten in zwei Schritten

  • Unternehmen. Firma und Rechtsform (GmbH oder UG), ob Sie gründen oder mit bestehenden Büchern umsteigen, der erste Tag der Bücher, ein leerer Ordner als Ablage für die Daten und der Eingang für neue Belege. Anschrift, Register und Steuernummer tragen Sie ein, soweit Sie sie haben.
  • KI-Agent verbinden. Sie wählen Ihren Client und richten ihn nach der Anleitung unten ein. Verbinden können Sie auch später.

Danach wählen Sie in den Einstellungen ein Sicherungsziel, am besten auf einem anderen Datenträger. Ohne Ziel sichert Buchfink nicht.

KI-Agent

3. Den Agenten verbinden

Solange Buchfink geöffnet ist, erreicht Ihr Client es unter http://127.0.0.1:7465/mcp. Bei der ersten Anmeldung öffnet sich der Browser; zustimmen tun Sie im Fenster von Buchfink. Die Skills bringen dem Agenten das Fachwissen mit, mit Quellen.

Claude Code

Plugin buchfink-buchhaltung mit Verbindung und Skills, oder claude mcp add.

Claude Desktop

Erweiterung buchfink.mcpb für macOS und Windows.

OpenCode

Eintrag in opencode.json, Skills mit npx skills add.

Codex

codex mcp add, Skills mit npx skills add.

Pi

pi mcp add, Skills mit npx skills add.

Was Sie Ihrem Agenten zeigen, geht an den Anbieter des Sprachmodells. Was das bedeutet.

Hilfe

Wenn etwas nicht klappt

  • Der Client erreicht Buchfink nicht. Buchfink muss laufen und ein Unternehmen geöffnet haben. Ist Port 7465 belegt, ändern Sie ihn in den Einstellungen und im Client.
  • Die Anmeldung hängt. Schauen Sie ins Fenster von Buchfink: Dort wartet die Anfrage auf Ihre Zustimmung.
  • Es bleibt dabei. Melden Sie den Fehler unter GitHub Issues, mit Programmversion, Betriebssystem, Client und den Schritten bis zum Fehler.

Was im Datenordner liegt

Je Unternehmen ein Ordner, die Ablage: die Datenbank buchfink.sqlite mit Buchungen, Stammdaten und Änderungsprotokoll, die Originalbelege unter belege/ und die Fassungen der Verfahrensdokumentation unter dokumente/. Dazu kommen der Eingang für neue Belege und der Exportordner für Dateien, die Ihr Agent erzeugt; beide liegen zunächst in der Ablage und lassen sich woanders hinlegen.

Legen Sie die Ablage nicht in einen Cloud-Ordner wie iCloud Drive, OneDrive oder Dropbox. Die Datenbank verträgt keine Synchronisation, während Buchfink läuft. Den Eingang dürfen Sie dorthin legen, etwa für eine Scanner-App auf dem Telefon.

Nichts davon ist verschlüsselt. Schalten Sie die Festplattenverschlüsselung Ihres Betriebssystems ein und legen Sie Sicherungen auf einem verschlüsselten Datenträger ab.

Buchfink

Quelloffene Buchhaltung für GmbH und UG in Deutschland. Läuft auf dem eigenen Rechner; ein KI-Agent arbeitet über MCP mit.
