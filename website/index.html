Buchhaltung für GmbH und UG.
Erledigt von Ihrem KI‑Agenten.

Sie legen Belege in einen Ordner und schreiben im Chat mit Claude, Codex oder einem anderen Agenten. Der bucht, erinnert an Fristen und bereitet Voranmeldung und Jahresabschluss vor. Sie geben nur noch frei. Buchfink ist quelloffen und kostenlos.

Ablauf

Belege hinlegen, Agent fragen, freigeben

Sie arbeiten im Chat, den Sie ohnehin kennen. Buchfink läuft daneben und zeigt, was gebucht ist.

Belege ablegen

Ziehen Sie Rechnungen und Kontoauszüge in den Eingang. Die Scanner-App auf dem Telefon speichert auf Wunsch in einen Cloud-Ordner, den Buchfink als Eingang liest.

Dem Agenten Bescheid geben

Schreiben Sie „Buche die Belege im Eingang.“ Der Agent liest sie, bucht die Routinefälle und fragt nach, wenn etwas unklar ist.

In der App freigeben

Sie sehen den Stand der Bücher und die nächsten Fristen. Monate festschreiben und Meldungen bestätigen Sie in der App.

Im Gespräch

Fragen Sie, wie Sie eine Buchhalterin fragen würden

Der Agent greift über Buchfink auf Ihre Bücher zu. Er beantwortet Fragen zu Ihren Zahlen, bucht, was eindeutig ist, und legt Ihnen vor, was eine Entscheidung braucht.

  • „Welche Rechnungen sind noch offen?“
  • „Wie viel Umsatzsteuer fällt für September an?“
  • „Welche Frist kommt als Nächste?“
  • „Bereite den Jahresabschluss vor.“

Was Buchfink übernimmt

Die Routine macht der Agent. Buchfink rechnet nach festen Regeln.

Buchfink kennt den Kontenrahmen SKR04, die Pflichtangaben einer Rechnung und die Fristen einer GmbH. Dadurch muss der Agent nicht raten, und Sie müssen nicht nachrechnen.

Belege lesen und buchen

PDF-Rechnungen, XRechnung und ZUGFeRD. Buchfink prüft Pflichtangaben und Steuerfall, der Agent bucht die Routinefälle.

Bankumsätze zuordnen

Kontoauszüge im Format CAMT.053 landen im Eingang. Ein Umsatz lässt sich auch auf mehrere Belege aufteilen.

Rechnungen schreiben

Ausgangsrechnungen als ZUGFeRD oder XRechnung, dazu Storno, Anzahlung und Schlussrechnung. Offene Posten behält der Agent im Blick.

Fristen im Blick behalten

Voranmeldungen, Vorauszahlungen, Jahresabschluss und Offenlegung leitet Buchfink aus Ihren Unternehmensdaten ab. Der Agent erinnert Sie.

Steuern vorbereiten

Umsatzsteuer-Voranmeldung, KSt, GewSt und E-Bilanz stellt Buchfink formularnah zusammen, jeden Wert mit seiner Herkunft.

Jahresabschluss aufbereiten

Bilanz und GuV nach HGB. Der Agent bereitet Abschreibungen, Abgrenzungen und Rückstellungen vor und bucht sie nach Ihrer Zustimmung.

Bücher

Jede Buchung zeigt ihren Beleg

In den Büchern sehen Sie, was der Agent gebucht hat, und finden zu jeder Zeile den Beleg dahinter.

  • Bücher mit Belegen, Bank und Buchungen an einem Ort
  • Das Original des Belegs bleibt unverändert
  • Korrekturen laufen als Storno und neue Buchung

Freigabe

Das letzte Wort geben Sie

Die Entscheidungen mit Folgen treffen Sie in der App. Der Agent bereitet sie vor, Buchfink nimmt sie nur von Ihnen an.

  • Monate und Jahre festschreiben
  • Übermittlungen an das Finanzamt bestätigen
  • Jahresabschluss aufstellen, feststellen und offenlegen
  • Unternehmensdaten, Gesellschafter und Bankkonten pflegen
  • Festlegen, was der Agent ohne Rückfrage bucht

Verbinden

Ihr Agent, Ihre Wahl

Buchfink spricht MCP, den offenen Standard für die Werkzeuge von KI-Agenten. Sie nutzen den Agenten, den Sie schon haben, und tragen Buchfink mit einem Befehl ein. Die Skills bringen dem Agenten das Fachwissen mit, jede Aussage mit Quelle.

Claude Code

Das Plugin richtet Verbindung und Skills in einem Zug ein.

claude plugin install buchfink-buchhaltung --marketplace mxzinke/buchfink
Anleitung

Claude Desktop

Eine Erweiterung für macOS und Windows. Doppelklick auf die Datei genügt.

buchfink.mcpb laden
Anleitung

Codex

Ein Befehl trägt den Server ein, ein zweiter meldet Sie an.

codex mcp add buchfink --url http://127.0.0.1:7465/mcp
Anleitung

OpenCode

Ein Eintrag unter mcp in Ihrer opencode.json.

"buchfink": { "type": "remote", "url": "http://127.0.0.1:7465/mcp", "enabled": true }
Anleitung

Pi

Ab Pi 0.99.0, mit Anmeldung über pi mcp login.

pi mcp add buchfink --url http://127.0.0.1:7465/mcp --exposure direct
Anleitung

Beim ersten Mal fragt Buchfink nach

Ein neuer Agent bekommt Zugriff, sobald Sie in einem Fenster von Buchfink zustimmen. Dort sehen Sie, welche App für welches Unternehmen Lesen oder Buchen möchte. In den Einstellungen entziehen Sie den Zugriff jederzeit wieder.

Für wen?

Für kleine GmbH und UG

Buchfink richtet sich an Gründer und kleine Gesellschaften mit überschaubaren Geschäftsvorfällen, mit oder ohne Steuerberatung.

Abgedeckt

  • GmbH und UG (haftungsbeschränkt), auch in Gründung
  • Dienstleistung, Software, Agentur, Projektgeschäft, Holding
  • Kleinst- und kleine Kapitalgesellschaften mit Bilanz nach HGB
  • Voranmeldung, Jahresabschluss, KSt, GewSt, USt und E-Bilanz vorbereiten

Nicht abgedeckt

  • Andere Rechtsformen und die Einnahmen-Überschuss-Rechnung
  • Istversteuerung, Kleinunternehmerregelung, Warenlieferungen ins Ausland
  • Kasse und Lohnabrechnung; das Lohnjournal Ihres Lohnbüros wird gebucht
  • Eigene Übermittlung an die Finanzverwaltung

Die vollständige Liste steht unter Umfang und Grenzen.

Open Source

Kostenlos, quelloffen, auf Ihrem Rechner

Buchfink gehört niemandem außer der Gemeinschaft, die es nutzt.

Kein Abo, kein Konto

Buchfink kostet nichts und braucht kein Benutzerkonto. Sie laden die App für macOS, Windows oder Linux und legen los.

Quelltext für alle

Die Lizenz ist die EUPL-1.2. Sie lesen nach, wie Buchfink rechnet, passen es an und geben Fehler und Wünsche auf GitHub weiter.

Jeder Agent passt

Sie wählen Agent und Sprachmodell selbst und wechseln, wann Sie möchten. Die Bücher bleiben, wo sie sind: in einem Ordner auf Ihrem Rechner.

Was Sie Ihrem Agenten zeigen, geht an den Anbieter des Sprachmodells. Dafür sind Sie verantwortlich. Mehr zur Datensicherheit.

Probieren Sie es mit einem Testunternehmen

Version 0.3 ist eine Vorschau, die Installationsdateien sind nicht signiert. Legen Sie ein Testunternehmen an, verbinden Sie Ihren Agenten und buchen Sie die ersten Belege.
