Installation

Buchfink installieren

Es gibt noch keine fertige Datei zum Herunterladen. Sie bauen Buchfink einmal selbst. Dafür kopieren Sie ein paar Befehle in ein Textfenster und drücken Enter. Programmierkenntnisse brauchen Sie nicht.

Planen Sie eine gute halbe Stunde ein. Den größten Teil davon wartet der Rechner.

Warum es keinen Download gibt

Buchfink ist eine Vorschau-Version. Fertige, signierte Programmdateien für macOS und Windows kommen mit der Version 1. Bis dahin bauen Sie das Programm aus dem Quellcode. Es sind dieselben Dateien, nur auf Ihrem Rechner zusammengesetzt.

Das Terminal öffnen

Drücken Sie Befehlstaste + Leertaste, tippen Sie Terminal und drücken Sie Enter. Es öffnet sich ein Fenster, in das Sie Text eingeben können. Jeden Befehl von dieser Seite kopieren Sie dorthin und drücken danach Enter.

Die Werkzeuge von Apple nachinstallieren

xcode-select --install

Ein Fenster fragt nach; bestätigen Sie es. Steht dort, die Werkzeuge seien schon installiert, ist alles in Ordnung. Gehen Sie zum nächsten Schritt.

Homebrew installieren

Homebrew ist ein Programm, das andere Programme installiert. Prüfen Sie mit brew --version, ob es schon da ist. Wenn nicht:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Sie werden nach Ihrem Anmeldekennwort gefragt. Beim Tippen bleibt das Feld leer. Das ist so gewollt. Am Ende nennt Homebrew ein oder zwei Zeilen, die Sie noch ausführen sollen; kopieren Sie sie und drücken Sie Enter.

Go, Node und Task installieren

brew install go node go-task

Wails installieren

go install github.com/wailsapp/wails/v3/cmd/wails3@latest echo 'export PATH="$PATH:$HOME/go/bin"' >> ~/.zprofile source ~/.zprofile

Die zweite und dritte Zeile sagen dem Rechner, wo er das eben installierte Programm findet.

Buchfink herunterladen

cd ~/Downloads curl -L -o buchfink.zip https://github.com/mxzinke/buchfink/archive/refs/heads/master.zip unzip -q buchfink.zip cd buchfink-master

Sie landen im entpackten Ordner. Von hier aus laufen die nächsten Befehle.

Buchfink bauen

task package

Der erste Lauf lädt viel herunter und dauert 10 bis 20 Minuten. Solange Zeilen durchlaufen, arbeitet er. Fertig ist er, wenn wieder eine leere Eingabezeile dasteht.

Starten

open bin/buchfink.app

Ziehen Sie bin/buchfink.app in den Ordner „Programme“, dann starten Sie Buchfink künftig wie jedes andere Programm. Beim ersten Öffnen meldet macOS, das Programm stamme von einem unbekannten Entwickler: öffnen Sie es mit Rechtsklick → Öffnen und bestätigen Sie.

PowerShell öffnen

Drücken Sie die Windows-Taste, tippen Sie PowerShell und drücken Sie Enter. Es öffnet sich ein Fenster, in das Sie Text eingeben können. Jeden Befehl von dieser Seite kopieren Sie dorthin und drücken danach Enter.

Go und Node installieren

winget install --id GoLang.Go -e winget install --id OpenJS.NodeJS.LTS -e

Schließen Sie das PowerShell-Fenster danach und öffnen Sie es neu. Erst dann kennt Windows die neuen Programme.

Wails und Task installieren

go install github.com/wailsapp/wails/v3/cmd/wails3@latest go install github.com/go-task/task/v3/cmd/task@latest $env:Path += ";$env:USERPROFILE\go\bin"

Die dritte Zeile gilt nur für das offene Fenster. Bauen Sie Buchfink später erneut, geben Sie sie wieder ein. Dauerhaft wird sie, wenn Sie den Ordner %USERPROFILE%\go\bin unter „Umgebungsvariablen bearbeiten“ eintragen.

Buchfink herunterladen

cd ~\Downloads Invoke-WebRequest -Uri https://github.com/mxzinke/buchfink/archive/refs/heads/master.zip -OutFile buchfink.zip Expand-Archive -Path buchfink.zip -DestinationPath . -Force cd buchfink-master

Sie landen im entpackten Ordner. Von hier aus läuft der nächste Befehl.

Buchfink bauen

task build

Der erste Lauf lädt viel herunter und dauert 10 bis 20 Minuten. Solange Zeilen durchlaufen, arbeitet er. Fertig ist er, wenn wieder eine leere Eingabezeile dasteht.

Starten

.\bin\buchfink.exe

Die Datei liegt im Ordner buchfink-master\bin. Sie können sie von dort per Doppelklick starten oder eine Verknüpfung auf den Desktop legen. Windows 10 und 11 bringen alles Weitere mit; nur auf einem älteren Windows fehlt gelegentlich die WebView2-Laufzeit, die Sie dann einmal nachinstallieren.

Ein Terminal öffnen

Auf den meisten Systemen mit Strg + Alt + T. Jeden Befehl von dieser Seite kopieren Sie dorthin und drücken danach Enter.

Die Systempakete installieren

Auf Ubuntu und Debian:

sudo apt update sudo apt install curl unzip build-essential pkg-config libgtk-4-dev libwebkitgtk-6.0-dev

Auf Fedora:

sudo dnf install curl unzip gcc pkgconf-pkg-config gtk4-devel webkitgtk6.0-devel

Go und Node prüfen

go version node --version

Nötig sind Go ab 1.25 und Node ab 20. Antwortet einer der beiden Befehle nicht oder nennt eine kleinere Zahl, holen Sie die Fassung von go.dev beziehungsweise nodejs.org. Die Pakete der Distribution sind oft älter.

Wails und Task installieren

go install github.com/wailsapp/wails/v3/cmd/wails3@latest go install github.com/go-task/task/v3/cmd/task@latest echo 'export PATH="$PATH:$HOME/go/bin"' >> ~/.bashrc source ~/.bashrc

Buchfink herunterladen

cd ~ curl -L -o buchfink.zip https://github.com/mxzinke/buchfink/archive/refs/heads/master.zip unzip -q buchfink.zip cd buchfink-master

Sie landen im entpackten Ordner. Von hier aus läuft der nächste Befehl.

Buchfink bauen

task build

Der erste Lauf lädt viel herunter und dauert 10 bis 20 Minuten. Solange Zeilen durchlaufen, arbeitet er. Fertig ist er, wenn wieder eine leere Eingabezeile dasteht.

Starten

./bin/buchfink

task package baut daraus zusätzlich ein AppImage sowie ein deb- und ein rpm-Paket. Dafür braucht es weitere Werkzeuge, und für den Anfang ist es nicht nötig.

Eine neue Fassung holen Sie später genauso: ZIP-Datei erneut herunterladen, entpacken, bauen. Die Werkzeuge sind dann schon da, und Ihre Buchhaltung liegt ohnehin in einem eigenen Ordner und nicht in dem des Programms.

Danach

Der erste Start

Ein Assistent fragt nach Firma, Rechtsform, Geschäftsjahr und dem Ordner, in dem Ihre Buchhaltung liegen soll. Danach steht die Aufgabenliste vor Ihnen.

  • Ihre Daten liegen in einem Ordner. Darin stehen die Datenbank, die Schlüsseldatei und die Originalbelege. Sie wählen ihn beim Einrichten; er gehört Ihnen und lässt sich verschieben.
  • Die Sicherung läuft mit. Beim Beenden und einmal täglich in einen zweiten Ordner Ihrer Wahl. Eine Sicherung ist eine gewöhnliche ZIP-Datei.
  • Wiederherstellen geht beim Start. Buchfink bietet die Sicherung an und prüft danach, ob die Daten unverändert sind.

Hilfe

Wenn etwas nicht klappt

  • „command not found“ oder „wird nicht erkannt“. Das Fenster kennt ein eben installiertes Programm noch nicht. Schließen Sie es, öffnen Sie ein neues und geben Sie den Befehl erneut ein.
  • Der Bau bricht mit einer Fehlermeldung ab. wails3 doctor prüft Ihr System und nennt, was fehlt.
  • Es bleibt dabei. Melden Sie den Fehler mit der letzten Bildschirmausgabe unter GitHub Issues. Bisher arbeiten wenige Anwender mit Buchfink, deshalb zählt jede Meldung.

Mitwirken ist willkommen: Fehlerberichte, Verbesserungen, Pull Requests. Der Ablauf steht in CONTRIBUTING.md, die Fachkonzepte liegen im Ordner docs/.

Was genau in dem Ordner liegt

Die Datenbank buchfink.sqlite, die Schlüsseldatei buchfink.keyfile.json und die Unterordner belege/ und dokumente/ mit den Originaldateien. Ein Mandant, ein Ordner.

Die Schlüsseldatei gehört zur Verschlüsselung der personenbezogenen Felder. Verlieren Sie sie zusammen mit dem Schlüsselbund des Betriebssystems, sind diese Felder nicht mehr lesbar. Sichern Sie beides.
