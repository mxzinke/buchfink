Installation

Bauen und starten

Es gibt noch keine fertigen Programmdateien zum Herunterladen. Buchfink wird aus dem Quellcode gebaut; das dauert einmalig ein paar Minuten und braucht drei Werkzeuge.

Voraussetzungen

  • Go ab Fassung 1.25
  • Node.js ab Fassung 20, mit npm
  • Wails v3 — go install github.com/wailsapp/wails/v3/cmd/wails3@latest
  • Task (empfohlen) — go install github.com/go-task/task/v3/cmd/task@latest
  • Typst (nur für das Rechnungslayout beim lokalen Erzeugen von PDF-Rechnungen)

Unter Linux kommen die üblichen Pakete für WebKit dazu; wails3 doctor meldet, was auf dem eigenen System noch fehlt.

Bauen

Terminalbash
git clone https://github.com/mxzinke/buchfink.git
cd buchfink
npm --prefix frontend install
task build

task build ruft wails3 build auf und legt das Programm im Ordner bin/ ab. task package erzeugt daraus das Paket für das jeweilige Betriebssystem.

Starten

Terminalbash
task dev                          # mit Hot-Reload, zum Entwickeln
./bin/buchfink                    # das gebaute Programm

Beim ersten Start führt ein Einrichtungsassistent durch Mandant, Rechtsform, Geschäftsjahr und den Datenordner.

Datenordner und Sicherung

Alle Daten eines Mandanten liegen in einem Ordner, den man beim Einrichten wählt: die Datenbank buchfink.sqlite, die Schlüsseldatei buchfink.keyfile.json und die Unterordner belege/ und dokumente/ mit den Originaldateien.

Buchfink sichert diesen Ordner beim Beenden und einmal täglich in einen zweiten, gewählten Zielordner; die Sicherung ist eine gewöhnliche ZIP-Datei und lässt sich ohne das Programm öffnen.

Beim Start bietet Buchfink die Wiederherstellung aus einer Sicherung an und prüft danach die Integrität der Hashketten.

Mitwirken

Fehlerberichte und Pull Requests sind willkommen. Wie der Ablauf aussieht, was vor einem Pull Request laufen sollte (task check) und welche Regeln für fremdes Material gelten, steht in CONTRIBUTING.md. Die Fachkonzepte — Architektur und Bedienkonzept, Anforderungskatalog, Stand der Umsetzung, Design-Konzept und Sicherheitskonzept — liegen im Ordner docs/ des Repositorys github.com/mxzinke/buchfink.

Buchfink

Buchhaltung für kleine bilanzierende Unternehmen. Läuft auf dem eigenen Rechner, erfüllt die GoBD, erzeugt Bilanz, GuV und E-Bilanz. Kostenlos und quelloffen.
